# Contribution Guidelines

Thanks for helping. Fixes are as welcome as new entries.

## Dead or moved links

If a link is dead or has moved, open a pull request that fixes or removes it, or open an issue saying which one. If a project has stopped being maintained but is still useful, move it to [Unmaintained & Archived](README.md#unmaintained--archived) with the year of its last commit.

## New entries

Anything useful about Canada can go in: lists, repos, APIs, datasets, sites, tools, communities and podcasts. Before adding one:

- Check it isn't already in the list.
- It should be maintained. Repos should have a commit in the last two years.
- Official government material that only lists services is better added to [wra-sol's Awesome Canada](https://github.com/wra-sol/awesome-canada#readme).

## Format

Add one entry per pull request, in the fitting section, in alphabetical order:

```md
- [Name](https://example.com) - Short description.
```

- The description starts with a capital letter and ends with a period.
- Keep it short and plain: say what it is, not why it's great.
- For an awesome list on GitHub, link to `https://github.com/owner/repo#readme`.

Pull requests are checked with [awesome-lint](https://github.com/sindresorhus/awesome-lint). You can run it yourself with `npx awesome-lint`.
